**Splatoon Weapon Guesser** is a browser game in which the player tries to identify a randomly chosen weapon from Nintendo's *Splatoon* series in five guesses.

## Gameplay
The player types the name of any weapon. The game then compares it with the hidden answer across seven attributes, and every attribute that matches lights up green:

| Attribute | Examples |
|---|---|
| Class | Shooter, Roller, Charger, Splatana |
| Sub weapon | Splat Bomb, Sprinkler, Angle Shooter |
| Special weapon | Inkjet, Tacticooler, Kraken Royale |
| Range | Very Short to Very Long |
| Damage | Very Low to Very High |
| Mobility | Very Low to Very High |
| Game | Splatoon 1, 2 or 3 |

Each guess narrows the field until the weapon is found or the guesses run out.

## Languages
The interface and weapon names are available in English, Chinese and Japanese, with the language picked automatically from the browser and switchable at any time.
